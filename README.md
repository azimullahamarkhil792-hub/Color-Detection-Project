
🎨 Color Detection System

Python-Based Color Detection Application

📌 About the Project

Color Detection System is a Python-based application designed to identify and detect colors from images.

The project helps users recognize different colors and display their color information through a simple graphical interface.

✨ Features

- Detect colors from images.
- Identify common color names.
- Display RGB color values.
- Display HEX color codes.
- Simple graphical user interface (GUI).
- Easy to use.

🛠️ Technologies Used

- Python
- OpenCV
- NumPy
- Tkinter
- Pillow

📂 Project Structure

Color-Detection-Project/
│
├── color_detection_fixed.py
├── run.bat
└── README.md

⚙️ Installation

Install the required libraries:

pip install opencv-python numpy pillow

▶️ How to Run

Run the following command:

python color_detection_fixed.py

Or run the application using:

run.bat

🎯 Project Purpose

The purpose of this project is to practice Python programming, image processing, and color detection techniques.
